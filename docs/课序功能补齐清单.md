# 课序功能补齐清单（仅功能性功能，按难度排序）

对比基准：课序 ClassFlow v1.11.1（`third_party/classflow-full/`）与 [课表功能并集与GitHub项目清单.md](../课表功能并集与GitHub项目清单.md) 的 148 项功能。

**本清单只含功能性功能**，已剔除外观与皮肤相关项：F131 主题切换、F132 主题色与课程配色、F133 背景/圆角/间距、F134 壁纸模糊与亮度；F136 桌宠课序已具备且属外观类，也不再列入。F137（本地免账号）、F138（PWA 离线）已具备。

结果：功能性缺口 **129 项**，其中易 21 项、中 54 项、难 46 项、极难 8 项。

## 难度口径

| 难度 | 判定标准 | 典型工作量 |
|---|---|---|
| 易 | 纯前端改动，不动数据模型或只加一个字段，无新依赖 | 单文件或单组件级 |
| 中 | 需要新增数据对象 + 迁移 + 视图，或接入一个浏览器/原生能力 | 一个完整模块 |
| 难 | 需要原生壳、服务端、OAuth、外部系统或模型推理 | 跨端或跨系统 |
| 极难 | 依赖校内实时数据或整个平台生态，个人项目难以落地 | 需外部合作方 |

模块顺序按「模块内最易一档」由易到难排列；模块内部同样严格由易到难。
