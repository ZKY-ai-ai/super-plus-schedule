## 标题

课隙 CourseGap：把「课间空档」算明白的离线课表助手（Qoder 全流程开发 + Qoder Sites 部署）

## 一句话介绍

课隙 CourseGap 是一个离线优先的大学生课表 PWA：导入课表后，它不只告诉你「下一节在哪上」，还算出「这节课间扣除走路和收拾后还剩多少可用时间、去图书馆再回来来不来得及、最晚几点出发」，并配合作业 DDL、考试倒计时与本地 AI 问答，全部数据只存在你自己的浏览器里。

## 为什么做它

调研了 GitHub 上 22 个课表 / 学习管理 / 校园 Bot 项目（Sleepy、拾光课程表、ClassFlow、Course_Planner、Gapwise、StudyDesk、qq-reminder 等，共 148 条功能条目）后发现一个共同缺口：**课表工具普遍只回答「有什么课」，很少回答「课间这段时间能干什么」**。Gapwise 做了步行与空档计算但面向加拿大校园数据；国内项目做了导入和提醒却不做空档规划；学习工具生成复习计划时又不检查课表冲突。

课隙把这三件事接在一起：课表（含单次调课）→ 空档引擎（扣除楼栋步行与缓冲）→ 任务 / 考试 / AI 问答共用同一份数据。调一次课，今日页、空档、提醒、ICS 导出全部跟着变，不需要在每个入口各维护一份课表。

同时坚持两条底线：**离线优先、无账号**（学生数据不出本机）；**100% 原创代码**（22 个参考项目只借鉴功能思路，许可证逐一核验，GPL/AGPL 代码零引入）。

## 怎么用（5 步）

1. 打开在线地址 https://coursegap-94kvqohlzrh.qoder.zone ，点「加载示例数据体验」（或从空白开始）。
2. 在「课表 → 导入」粘贴 / 上传你的课表文件：支持本项目 JSON、WakeUp 风格 JSON、CSV、ICS；导入前有预览，可选替换 / 追加 / 合并。
3. 在「设置」里填开学日期、教学周数，按楼栋配置步行时间（教室名自动前缀匹配楼栋）。
4. 日常看「今日」：下一节课与最晚出发时间、今日 DDL、考试倒计时；看「空档」：每个课间的可用分钟数与去处建议，或用往返计算器问「去图书馆再回来来得及吗」。
5. 在「AI 助手」直接问「明天下午有空吗」「下周考试前还剩多少空档」；不配密钥也能用（离线规则问答），配置 OpenAI 兼容接口后解锁自由问答与截图识课（识课结果人工核对后才导入）。

换机迁移：设置 → 导出完整备份 JSON，新设备恢复即可。可安装为 PWA 离线使用。

## 功能清单（核心包）

- 课表：周网格 / 周列表 / 日视图，多课表多学期，起止周 + 单双周 + 逐周勾选，多时段，冲突红框，点击单次停课 / 调课，拖拽调课，撤销 / 重做，PNG 导出与打印
- 导入导出：JSON / WakeUp / CSV / ICS 导入（预览 + 三种合并策略）；ICS 导出含单双周 RRULE、调课 EXDATE 与课前 VALARM；完整备份
- 今日：正在上课 / 下一节 / 最晚出发、DDL 分组、考试倒计时、周统计
- 空档：可用时间 = 空档 − 去程 − 回程 − 缓冲；往返可行性与最晚返回时间；去处建议
- 任务 / 考试：优先级、子任务、逾期分组；座位号与考前 1 / 3 天提醒
- AI：离线规则问答默认全本地；可选模型增强与截图识课（强制人工核对）
- 隐私：无账号、无追踪、无云同步；密钥仅存本机
