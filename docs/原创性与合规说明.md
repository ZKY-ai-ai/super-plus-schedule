# 原创性与合规说明

核验日期：2026-11-16。本文档说明课隙 CourseGap 的原创性立场、参考边界与许可证核验结果，供大赛评审与后续复用者查阅。

## 1. 原创性立场

1. 本项目全部源代码（HTML / CSS / JavaScript / Service Worker / 测试）由开发者在 Qoder 中原创编写，未复制、翻译、改写任何参考项目的源码片段。
2. 参考输入仅限两类：各项目公开 README / 文档中的**功能描述**，以及整理文件《课表功能并集与GitHub项目清单.md》中的功能条目。功能思路、交互模式、数据格式惯例不属于著作权保护的表达，借鉴思路不构成侵权。
3. 未使用任何参考项目的名称、Logo、图标、截图、文案作为本项目素材。应用图标为原创 SVG；示例课程与教师姓名为虚构。
4. 兼容公开数据格式（ICS RFC 5545、WakeUp 风格 JSON 字段惯例、CSV）属于接口兼容，格式字段名本身不构成受保护表达；解析与生成代码均为原创实现。
5. 本项目沿用仓库预先声明的 **Mulan PSL v2（木兰宽松许可证 第2版）** 发布。该许可证为宽松型（OSI 认证），与所有参考项目的许可证兼容（未引入其代码，故无 copyleft 义务）。

## 3. 能力边界（不夸大的部分）

1. 无教务直连：不抓取任何学校教务系统，不保存学校账号密码；课表来源为用户手动录入或文件导入。
2. 无实时数据：空教室、成绩、电费、座位预约等逐校服务能力未实现，也不以模拟数据冒充。
3. 步行时间为可配置估算矩阵，不是地图路径规划；界面明确标注参数来源。
4. AI 截图识课依赖用户自配视觉模型，结果带「待核对」标记并经导入预览确认，不自动写入。
5. Web 提醒仅在页面打开期间生效；不承诺后台推送、自动静音等原生系统能力。
6. ICS 导出为静态快照；日历订阅刷新取决于日历客户端，不是双向同步。
7. 示例数据明确标注为示例，可在设置中一键清空。

## 4. 隐私合规

- 无账号体系、无分析埋点、无第三方脚本、无云端同步。
- localStorage 仅存业务数据与用户自填的 AI 接口配置；密钥不出本机。
- AI 增强请求仅发往用户填写的 endpoint；离线层完全本地运行。
- Service Worker 仅缓存同源静态资源，不拦截外部请求。

## 5. 复用指引

若后续开发者希望真正复用某参考项目的代码（而非思路），须先按其许可证履行义务：GPL / AGPL 项目要求衍生作品同许可证开源并保留声明；Apache-2.0 要求保留 NOTICE 与声明；未找到 LICENSE 的项目须先取得作者授权。本项目当前不包含任何此类复用。
