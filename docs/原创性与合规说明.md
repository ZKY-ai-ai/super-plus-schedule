# 原创性与合规说明

核验日期：2026-11-16（第三方代码引入部分同日更新）。本文档说明课隙 CourseGap 的原创性立场、**已引入的第三方代码及其归属**、参考边界与许可证核验结果，供大赛评审与后续复用者查阅。

> 重要变更：本项目自 2026-11-16 起**不再是「全部代码原创」**。课表引擎、空档分析、导入导出、AI 助手、视图与样式等主体代码仍为原创；另有四个纯逻辑模块移植自 MIT 许可的课序 ClassFlow，已保留上游版权声明与许可证全文。逐文件归属见 [third_party/classflow/NOTICE.md](../third_party/classflow/NOTICE.md)。

## 1. 原创性立场

1. **原创部分**：应用壳（HTML / CSS）、状态与持久化、教学周与课次展开引擎、冲突检测、空档与往返可行性模型、JSON / CSV / ICS / WakeUp 导入导出、PNG 导出、离线 AI 规则问答与可选模型增强、七个视图、编辑弹窗、Service Worker、冒烟测试，以及桌宠「小隙」的 SVG 形象与课程配色方案，均由开发者在 Qoder 中原创编写。
2. **第三方部分（已引入代码）**：作息按「月-日」年度循环、法定节假日与调休判定、课表模板清单与课程种子数据、壁纸渐变配方与图片压缩流程，四部分逻辑移植自 `lcymxm/classflow`（MIT）。上游为 TypeScript + React 数据模型，本项目按自身 `periodSets / schedules / courses` 结构改写为无依赖纯函数，**算法与数据表保留上游表达**，因此按 MIT 履行保留版权与许可证声明的义务。
3. **仅借鉴思路部分**：其余参考项目的公开 README / 文档中的功能描述，以及《课表功能并集与GitHub项目清单.md》中的功能条目。功能思路、交互模式、数据格式惯例不属于著作权保护的表达。
4. 未使用任何参考项目的名称、Logo、图标、截图、文案作为本项目素材。应用图标与桌宠形象为原创 SVG；示例课程与教师姓名为虚构。**ClassFlow 的鲸鱼娘 / dsh-pet 素材与 `whale-night` 壁纸预设未引入**：上游 README 将其限定为免费非商业使用，且涉及 DeepSeek 商标，与本项目 Apache-2.0 发布及参赛用途不兼容。
5. 兼容公开数据格式（ICS RFC 5545、WakeUp 风格 JSON 字段惯例、CSV）属于接口兼容，解析与生成代码均为原创实现。
6. 本项目以 **Apache-2.0** 发布，版权署名 ZKY-ai-ai。Apache-2.0 与 MIT 兼容：引入的 MIT 代码保留原始版权声明与许可证全文（`third_party/classflow/LICENSE`），并在 NOTICE 中逐文件标注来源与提交号，满足 Apache-2.0 第 4 条对第三方声明的要求。未引入任何 GPL / AGPL / 未授权代码，故无 copyleft 义务。

## 5. 能力边界（不夸大的部分）

1. 无教务直连：不抓取任何学校教务系统，不保存学校账号密码；课表来源为用户手动录入或文件导入。
2. 无实时数据：空教室、成绩、电费、座位预约等逐校服务能力未实现，也不以模拟数据冒充。
3. 步行时间为可配置估算矩阵，不是地图路径规划；界面明确标注参数来源。
4. AI 截图识课依赖用户自配视觉模型，结果带「待核对」标记并经导入预览确认，不自动写入。
5. Web 提醒仅在页面打开期间生效；不承诺后台推送、自动静音等原生系统能力。
6. ICS 导出为静态快照，**不含节假日停课与调休映射**；日历订阅刷新取决于日历客户端，不是双向同步。页面与 PNG 导出则与校历设置一致。
7. 示例数据明确标注为示例，可在设置中一键清空。
8. **Android 桌面小组件（F068 / F069）未实现**：本项目为零构建静态 PWA，小组件需要 Capacitor 等原生壳，不在本轮范围。
9. 节假日内置数据仅覆盖 2026 / 2027 年，且未独立核验政府原文；其他年份需用户逐日自定义。
10. 桌宠为页面内浮动 SVG 形象，不是操作系统级桌面宠物；关闭页面即消失。

## 6. 隐私合规

- 无账号体系、无分析埋点、无第三方脚本、无云端同步。
- localStorage 仅存业务数据、用户自填的 AI 接口配置与自定义壁纸图片（压缩后的 dataURL）；密钥与图片均不出本机。
- AI 增强请求仅发往用户填写的 endpoint；离线层完全本地运行。
- Service Worker 仅缓存同源静态资源，不拦截外部请求。
- 引入的第三方代码均为纯逻辑模块，不含网络请求、埋点或远程资源加载。
