# 课表软件在线入口与安装包清单

整理日期：2026-11-16，来源：仓库根目录《课表功能并集与GitHub项目清单.md》的 P01–P22。

## 0. 本清单做了什么

- 逐个查询 22 个 GitHub 仓库的 `homepage`、Pages 站点、最新 Release 及其资产，用 HTTP 请求验证入口可达、用 Range 请求验证安装包可下载。
- 把 Android/iOS 安装包全部下载到仓库根目录 `安装包/`，逐个比对 GitHub API 报告的资产字节数；上游提供校验和的包（P01、P02、P05）已按其 `sha256sums` 比对，全部一致。
- 只做可达性与完整性核验，**没有安装、登录学校账号或运行这些软件**，功能描述仍以各项目 README 为准。

`安装包/` 保持未跟踪，二进制不进版本库。

## 5. 使用提示

1. **ABI 选择**：近 3 年国内主流手机用 `arm64-v8a`；不确定就装 `universal`（仅 P01 提供）。`x86_64` 面向模拟器/Win11 安卓子系统。
2. **来源风险**：全部走 GitHub Release 直装 sideload，不经应用商店。除 P01、P02、P05 外，上游没有提供校验文件，第 2 节表里的 SHA-256 是本次下载后本机的值，只能证明"下载未被改动破坏"，**不能证明作者签名可信**。装前可用 `apksigverify`/Android Studio 或 `keytool -printcert -jarfile` 看一眼签名者。
3. **P06、P22 是学校专用客户端**（北科大、武大），换学校装不上教务；P08 是国科大杭州高研院特定届别数据。
4. **P12 冷启动**：Render 免费实例会被休眠，第一次访问等 30 秒以上属正常。
5. **P10 依赖通义千问视觉服务**，识别结果需人工核对；两个入口功能相同，域名不同。
6. **P15 的 WakeUp APK** 标了"非官方分发"，仅用于口令格式联调，不建议当日常客户端安装。
