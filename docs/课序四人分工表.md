## 六、协作节奏

1. 阶段 0 期间统一在 `main` 上小步提交，拆完后再开功能分支。
2. 功能分支命名 `feat/<模块>-<编号>`，一次提交只做一个功能。
3. 每天每人 rebase 一次 `main`；schema 变更单独 PR，由甲合并。
4. 阶段末联合验收：`pnpm test` + `pnpm build` + 四人交叉检查对方模块。
5. 群协作与 AI 涉及外部服务，先在阶段 2 把接口留好，阶段 3 再接真实服务。
