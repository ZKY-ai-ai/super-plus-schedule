# 课序双人分工表

分工对象：[课序功能补齐清单](课序功能补齐清单.md) 中的 129 项功能性缺口。目标是在两人并行开发时，功能量接近、冲突面可控。

权重口径：易 1 分、中 3 分、难 6 分、极难 10 分（对应改动面与联调成本，不是工时）。

**总量：甲 270 分，乙 269 分。**

## 一、分工原则

1. **按数据对象与文件所有权切，不按「页面」切。** 页面共享，数据对象和模块文件独占。
2. **甲负责课表内核与对外通道**：overrides、校历/导入/导出、空档引擎、群机器人与多用户。
3. **乙负责学习管理**：任务、考试、提醒、统计、笔记、AI、选课规划。
4. **共享文件单一所有者**：数据模型与迁移由甲统一合入，乙提字段需求；其余文件按下表归属。
5. **每阶段末对齐一次接口**，阶段内允许各自合并，不做长期分支。

## 八、协作节奏

1. 两人都从 `main` 切 `feat/<模块>`，小步提交，单次改动不超过一个功能。
2. 每天至少同步一次 `main`：先 rebase 再推，避免长分支。
3. schema 变更单独成 PR，由甲合并，合并后通知乙重新拉取。
4. 阶段末做一次联合验收：跑 `pnpm test` 与 `pnpm build`，两人交叉检查对方新增模块。
