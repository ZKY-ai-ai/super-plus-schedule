## 二、赛制速览（官方核实）

- **主办/赞助**：Qoder / NVIDIA。全国在校大学生（本专科硕博含港澳台），不限专业，**1–3 人组队**，单人可参赛。
- **时间**：报名与发布 10/29–**11/30 18:00**；初筛 12/1–7，**每赛道 14 队进决赛（共 42）**；决赛 12/1–15 线上直播路演。
- **奖金池 ¥88,500**：一等奖 ¥5,000×2/赛道、二等 ¥3,000×3、三等 ¥2,000×4、优秀 ¥500×5；参与奖限 2000 份（帆布袋+抽奖）、社交传播奖限 1000 份（零钱包，需小红书/抖音/X @qoder 带话题）。另有官方证书、案例推广、实习内推、付费会员 1 年。
- **硬性提交要求**：
  1. **Qoder 开发 + Qoder Sites 公网部署**，评委点开即用；原则上不接受本地文件/压缩包。
  2. 帖子**标题注明赛道**，正文五部分：自我介绍 / 作品是什么（谁在什么场景用）/ 为什么做 / 怎么用（≤5 步）/ 用 Qoder 做的过程（多截图）。
  3. 写明所用 **Qoder 账号**；全员完成天池实名 + 阿里云大学生认证。
- **评分四维**：问题是否真实 · 核心流程是否走得通 · 体验与设计 · Qoder 使用深度。**技术复杂度不计分**；三赛道均收非代码作品；不限提交份数但每队限获一项现金奖（取最高分）。

> 策略含义：评委要的是「一个真实问题被又快又好用解决」，不是「一套复杂系统」。选题应优先选**问题真实、流程短、体验好**的切口，而非技术堆料。

### 3.2 扎堆区（红海）

- **文献矩阵/综述生成严重撞名**：PaperMatrix / LitMatrix / 文献棱镜 / 文献对比矩阵 / PaperMatrix 等 ≥5 件做同一件事；**「PaperLens」被 3 个不同作者独立撞名**（[1096694](https://tianchi.aliyun.com/forum/postDetail?postId=1096694)、[1095420](https://tianchi.aliyun.com/forum/postDetail?postId=1095420)、[1097349](https://tianchi.aliyun.com/forum/postDetail?postId=1097349)）。再交一个「把 PDF 变矩阵」很难被记住。
- **Lab\* 实验数据台**：LabDesk / LabKit / LabClean / LabInsight / LabBench / LabPilot / LabCurve / LabFig… 名字与功能高度同质（上传数据→出图→出报告）。
- **课程可视化实验室**：PLC 实训台 ×2、机构工坊 ×2（已合并）、算法可视化 ×4（演算场/算法剧场/看见算法/算法之城）。

### 3.3 空白/薄弱区（对照官方示例）

官方点名但投稿偏少的方向：
- **课表与作业管理**：仅 13 件，且多为通用效率工具，缺「冲突检测/截止预警」的深做。
- **实习信息聚合**：仅实习雷达、CodeRun、FLY 等数件，缺「可信度审计/过期过滤」。
- **多模态应用**（公式识别、图表理解、讲义转写）：FormulaLens、EchoDeck、ChartLens 等零星几件，远少于文献类。
- **文献「核验/审计」侧**：生成类扎堆，但 RefCheck/假通过/翻案这类「挑错」工具相对少——红海里的差异化缝隙。

### 3.4 选题建议（差异化切口）

1. **公式/图表多模态讲解器**：拍教材或课件里的公式 → 逐步推导 + 前置概念卡 + 3 道自测题。避开文献矩阵红海，命中官方「多模态」示例，问题真实（理工科看不懂公式）。
2. **实习信息「可信体检」聚合**：只收企业官方招聘页/高校就业网源，每条标来源+截止+真伪标签，自动过滤过期与中介假帖。比通用聚合多一层「可信审计」。
3. **课表×作业冲突工作台**：导入课表截图+作业要求 → 生成周计划并标红时间冲突/截止临近，不登录不上传。命中薄弱区，流程≤5 步。
4. **实验「负结果」档案**：记录失败实验与条件，生成课题组共享的「此路不通」地图。与正向出图的 Lab\* 台反向定位，科研痛点真实。
5. **结论证据链校对器**：粘贴论文/报告结论 → 回溯到原文 PDF 页码或数据表，标红「无支撑主张」。做文献红海里的「挑错」而非「生成」。

### 4.3 空白/薄弱区（对照官方示例）

- **社团工具**（官方示例：招新页/活动报名/作品集展示）：仅社团一站、百团AI工坊、社团招新AI分部门、校园活动制作、班班有解 ≈5–6 件，远少于游戏。**官方点名却少人做**。
- **宿舍公约 / 约饭投票**（官方示例）：几乎无专门作品，多被「今天吃什么」覆盖但无「公约/投票」机制。
- **音乐「练习/实用」侧**：22 件多为生成式玩具，缺「乐器练习伴奏/慢速循环」这类实用工具。
- **生活工具差异化**：35 件多为通用番茄钟/格式转换，缺与校园真实场景深绑定的工具。

### 4.4 选题建议（差异化切口）

1. **宿舍公约 & 约饭投票器**：生成值日/水电分摊公约 + 一键约饭/出游投票，结果可直接发群。命中官方示例空白，问题真实（宿舍扯皮），流程极短。
2. **社团招新全流程站**：招新页 + 报名表 + 自动面试排期 + 报名数据看板。比现有「只生成招新页」多走「报名→排期→复盘」闭环。
3. **乐器练习伴奏工具**：导入一段曲子 → 慢速/循环/A-B 重复/节拍器，服务练琴而非生成音乐。音乐簇里的实用差异化。
4. **订阅+账单统一审计**：把订阅管理与账单整理合成一张「钱去哪了」月报 + 一键退订建议。记账红海里的整合切口。
5. **校园实景定向/打卡游戏**：以真实校园地图为棋盘（定向越野/打卡/跑步画图），把线上游戏与线下校园连接。游戏红海里靠「实景」差异化。

> 游戏并非不能做：评分看体验而非复杂度，一个**机制独特、3 分钟上手、打磨精致**的小游戏仍可在 89 件里突围（参考涂鸦乱斗 587、海龟汤 507 的非主流机制）。但「再做一个割草/肉鸽」风险极高。

### 5.2 扎堆区（红海）

- **适老 + 反诈高度重叠**：老年数字鸿沟 26 + 反诈 32，其中大量是「给爸妈/老人的防诈/手机练习」，合计近 60 件指向同一人群同一痛点。大字版手机教程/模拟手机 ×6+（慢慢点/慢慢来×2/手机明白/手把手/银发数字练习厅/爸妈手机练习场）。
- **用药安全**：念药/药安心/药明白/电子药盒/用药管家/合理用药 ≈10 件，多为「说明书翻译+提醒」。
- **沟通板**：手心语/易言/星星心语板 ×3，形态接近。

### 5.3 空白/薄弱区（对照官方示例）

- **无障碍出行导航**（官方示例）：仅梯安（电梯）、通道提醒（居家）等，**户外盲道/轮椅坡道/无障碍路线导航几乎空白**。沟通板多、出行少。
- **慢病记录**（官方示例）：用药提醒多，但**血压/血糖等慢病自我记录+家庭共享极少**（心脑血管/肾络偏影像分析，非日常管理）。
- **留守儿童陪伴**（官方示例）：仅小禾周记（家校沟通），**「陪伴」侧几乎无人做**。
- **碳足迹记录**（官方示例）：仅碳溯星图、电优助手 2 件，家庭级碳账本薄弱。
- **心理健康实用干预**：8 件多为抽象觉察/札记，缺「考前恐慌/社交焦虑」等具体场景的 90 秒可操作微干预。
- **文化遗产数字化**：数字圆明园 372 浏览证明需求，但仅 2 件——**高关注、低供给的新兴缝隙**。

### 5.4 选题建议（差异化切口）

1. **慢病大字日志 + 家庭共享**：血压/血糖一键记录 → 大字趋势图 + 异常提醒 + 子女远程可见。命中官方「慢病记录」空白，人群真实（慢病老人），流程短。
2. **户外无障碍导航**：盲道/轮椅坡道/电梯状态标注 + 无障碍路线规划。无障碍簇里从「沟通」转向「出行」，官方示例却少人做。
3. **留守儿童「声音陪伴」周报**：孩子录一段话 → 在外父母收听并回录 → 生成每周陪伴小结。从「家校沟通」转向「亲子陪伴」，命中空白。
4. **家庭电费碳账本**：上传电费单 → 翻译成碳排放 + 省钱建议 + 同小区对比。环保簇里碳足迹仅 2 件，切口具体。
5. **地方文化遗产数字档案**：本地非遗/老照片/老建筑 → 可检索可分享的数字站点。圆明园 372 浏览验证需求，供给极少，易出传播力。

## 六、跨赛道规律与提交策略

### 6.1 高浏览作品的共性

- **一句话价值主张 + 具体人群/场景**：Mingleaf「让不敢开口的同学也能轻松组队」、pastpapers.cn「英语真题在线」、大肥鱼「Token 海摸鱼图鉴」、手心语「无触控沟通板」。标题即说清「谁在什么场景用」。
- **情绪共鸣/叙事化标题**：「医生说的每句话都对，可我妈就是听不懂」「先被骗一次，才不容易真正被骗」「把宿舍群聊改编成一局联机桌游」——比功能罗列更抓人。
- **每日 demo 连载帖**：多件作品标注「每日 demo 参赛帖」，持续更新带来累积曝光。
- **本地优先/隐私卖点**：「照片不出浏览器」「不登录不上传」「原始数据不出浏览器」反复出现，是体验加分项。

### 6.2 合规红线（务必自查）

抓取正文中发现部分帖子主链接为**本地或非 Qoder 部署地址**，违反「Qoder Sites 公网部署」硬性要求，需替换：
- `file:///` 本地文件：助力乡村振兴（[1097680](https://tianchi.aliyun.com/forum/postDetail?postId=1097680)）、智能学习助手（1097574）、绪叙（1095340）、产品介绍（1095638）。
- `localhost` / `127.0.0.1`：小芽健康（1096550）、ScamShield（1095393）、Windows灵动岛（1097336）、开源星图观测台（1096261）。
- 非 Qoder 部署（netlify）：赛博木鱼（1097852）、银发向善（[1093899](https://tianchi.aliyun.com/forum/postDetail?postId=1093899)，149 浏览）。

> 这些作品本身创意不错，但若主链接不是 Qoder Sites 公网地址，**可能直接判不合格**。提交前用「评委视角」点开自己的链接验证。另：个别作品注明素材来自公众号/搬运，需确保原创。

### 6.3 选题决策框架（建议照此自检）

1. **问题真实吗？** 能否一句话说清「谁在什么场景下需要它」，且这个人就在你身边。
2. **核心流程 ≤5 步走得通吗？** 评委不看说明书就能用起来。
3. **避开撞名/同质吗？** 文献矩阵、Lab\* 数据台、奶蛙割草、表情包工厂、大字手机教程——这些名字和形态已被占满，换切口或换人群。
4. **体验有记忆点吗？** 一个独特机制/一句共鸣标题/一个隐私卖点，胜过十个通用功能。
5. **Qoder 过程讲得清吗？** 哪几步交给 Qoder、你改了什么、多截图——这是评分第四维，别只晒结果。
6. **技术复杂度不计分**：把一个小工具打磨得又快又好用，比堆一套多 Agent 系统更划算。

### 6.4 时间策略（剩 14 天）

- 不限提交份数但**每队限获一项奖**：与其铺 5 个半成品，不如聚焦 1–2 个打磨到「打开即用」。
- 优先选**空白区**（社团工具、宿舍公约、慢病日志、无障碍出行、留守儿童陪伴、碳账本、文化遗产）——供给少、官方点名、问题真实。
- 红海并非禁区，但必须**差异化切口 + 精致体验**，否则淹没在同质投稿里。
- 尽早完成实名+学生认证、领取 Qoder CN 学生权益；发布后持续更新 demo 并做社交传播（另有传播奖）。
- 方法论先例：[调参人生实验室](https://tianchi.aliyun.com/forum/postDetail?postId=1092756) 作者用 3 个研究子代理生成 9 个候选选题再择优——本报告即同类「先扫描全景再定位切口」的思路。
