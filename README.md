# 超级无敌plus课表

大学生课表工具的开源仓库，目标是吸收现有课表类项目的功能并集，做一个覆盖导入、展示、提醒和校园服务的课表产品。

## 当前状态

项目处于功能调研与规划阶段，仓库里目前只有一份调研资料，尚无代码实现。

| 路径 | 说明 |
|---|---|
| [课表功能并集与GitHub项目清单.md](课表功能并集与GitHub项目清单.md) | 22 个同类开源项目的功能并集（148 条），按 15 类模块整理，用于确定功能范围 |

## 规划中的模块方向

功能清单已经划分出以下方向，后续按优先级逐个落地：

- 课表展示与课程编辑
- 课表导入与识别
- 提醒与通知
- 教务系统适配
- 多端与数据同步

具体技术栈、目录结构和合作规范会在第一次实现提交时补充到本文件。

## 协作

仓库在码云（Gitee）托管，采用分支 + PR 流程：

1. 从 `main` 切出功能分支，命名 `feat/<内容>` 或 `fix/<内容>`。
2. 提交信息用动词开头说清改动，一个提交只做一件事。
3. 发起 PR，由另一位协作者审核后合入 `main`。
